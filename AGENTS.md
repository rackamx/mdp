* Practice TDD (Test Drive Development)
  * Write the test first (it should fail, since you haven't written the code yet)
  * Write the code
  * Run the test, now it should work. If not, debug and iterate until the tests passes.

* Tasks refer to tasks in PLAN.md doc, e.g. T10

* When working on a task, create one single commit where you have the code, the
  tests and the update of PLAN.md to mark the test complete. 

* If there are instructions you don't understand, don't silently skip them, ask
  the user for clarifications.
