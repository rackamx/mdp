* Practice TDD (Test Drive Development)
  * Write the test first (it should fail, since you haven't written the code yet)
  * Write the code
  * Run the test, now it should work. If not, debug and iterate until the tests pass.
  * Before committing, ensure all relevant tests pass. Do not introduce skipped or flaky tests.

* When working on a task, create one logical commit per task when feasible, including both code and tests.
  If the task came from a markdown document, mark the task as done in that document in the same commit.
